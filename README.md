# Bashademy — Digital Product Company website

A responsive, static website for Bashademy, positioned as a digital product company offering software and web development, SEO and digital marketing. Built with plain HTML, CSS and JavaScript; ready for GitHub Pages.

## Before publishing

1. Open `index.html`.
2. Find `mailto:YOUR_EMAIL_ADDRESS` and replace `YOUR_EMAIL_ADDRESS` with your real business email.
3. Review the wording and update any company details you want to make more specific.
4. Keep `index.html`, `styles.css`, `script.js` and the `assets` folder together.

## Publish with GitHub Pages

1. Create a GitHub repository. For a user/organisation site, the repository can be named `yourusername.github.io`. For a project site, any repository name is fine.
2. Upload all files and folders from this package to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide the published website address after deployment.

No build tools, frameworks, server or database are required.

## Custom domain

After the GitHub Pages site is live, add your domain under **Settings → Pages → Custom domain** and configure the DNS records at your domain registrar. Enable HTTPS when GitHub Pages makes it available.

## Notes

- The contact link uses a placeholder email address and must be updated before launch.
- Google Fonts are loaded from Google Fonts; system fallbacks are included.
- This is a static front-end website. The contact link opens the visitor's email app; it does not submit to a backend.
