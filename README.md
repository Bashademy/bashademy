## GitHub Pages publishing

1. Upload the contents of this folder to the root of the GitHub repository.
2. In GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Confirm your custom domain is set to `bashademy.com` in GitHub Pages and that DNS is configured at your registrar.
5. Enable HTTPS once GitHub Pages offers it.

## SEO launch checklist

1. Confirm `https://bashademy.com` is the canonical live domain. If you use `www` instead, update canonical tags, sitemap and structured data consistently.
2. Verify the domain in Google Search Console.
3. Submit `https://bashademy.com/sitemap.xml` in Search Console.
4. Inspect the homepage and key service URLs with URL Inspection.
5. Connect an analytics tool if you want to measure enquiries and website actions.
6. Replace any sample or placeholder portfolio content with real client work and approved metrics.
7. Add real social embed snippets only after obtaining client permission.
8. Keep business information and service claims accurate. Do not publish invented testimonials, clients, rankings or performance figures.

## Portfolio page: how to add a real project

In `our-work.html`, replace each `[Client / project name]`, placeholder description, and bracketed metric with client-approved information. For social content, replace the `.embed-placeholder` element with the official embed code provided by Instagram, Facebook, LinkedIn or YouTube. Check the platform's current embed requirements and privacy settings.

For growth charts, replace the illustrative bars with a chart or screenshot based on real data. Always label the source, metric and reporting dates. The current chart is explicitly marked as a placeholder and must not be presented as an actual result.

## Important SEO notes

- Every page has its own title, meta description and canonical URL.
- The site includes Organization, WebSite, Service and Article structured data where relevant.
- `robots.txt` points crawlers to the XML sitemap.
- Use helpful, original content and natural language. Do not keyword-stuff pages or create thin pages just to target keyword variations.
- Search rankings cannot be guaranteed. SEO performance depends on competition, relevance, site quality, links, reputation, content and ongoing work.
- This static website does not include a CMS or server-side form. WhatsApp links open a direct chat.

## Before launch

Review all wording and confirm that every service listed is actually offered. The portfolio is intentionally a template: no client names, social posts or growth results have been invented.
